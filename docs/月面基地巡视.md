# 月面基地巡视

## 展示与操作

在「月表漫游 → 环游月面基地」进入基地。五个镜头依次观察基地全景、生活与实验舱、太阳能阵列、通信站、着陆保障区；区域之间平滑过渡，各区域内部缓慢环绕。

- 暂停/继续控制自动巡视；上一站、下一站或区域按钮定位并停留。
- 点击场景中的设施或名称标注，同样定位对应区域。
- 自由观察允许拖动旋转、滚轮缩放，围绕当前设施观察；返回自动巡视时平滑接回镜头。
- 巡视设置提供速度、区域标注开关和重新巡视。
- 退出、切换漫游方式或离开工作区时，释放设施、标注与镜头控制，恢复相机参数。

## 实现边界

模型是本项目原创的月面基地概念设计，不对应已建成基地或某个机构的工程部署方案。科普叙述说明通用功能；位置、尺寸、设施间距和巡视路线用于视觉组织，不作为工程设计参数。

模型直接布置在主月球场景，沿用当前月球椭球与地形高程。第一人称、第三人称和月球车场景共享这组设施。没有新增外部模型请求或依赖包。

## 代码分工

| 文件 | 职责 |
| --- | --- |
| `src/data/lunarBase.ts` | 区域内容、相机目标、距离、高度、角度、停留时间 |
| `src/stores/baseTour.ts` | 播放、区域、观察方式与界面设置 |
| `src/components/BaseTourControls.vue` / `src/base-tour.css` | 按需显示的基地巡视面板 |
| `src/scene/LunarBaseModel.ts` | 设施几何、分组拾取、高亮、步行碰撞与资源释放 |
| `src/scene/BaseTourNavigation.ts` | 平滑镜头、区域巡视、自由观察与场景标注 |
| `src/scene/SurfaceNavigation.ts` | 基地、步行、月球车的生命周期整合 |

路径相对 `moon-web/web/`。设施拾取统一使用 `base:<区域ID>`，面板与地图操作共享同一状态。修改模型布局时，同步调整对应区域的镜头目标及步行碰撞范围。
