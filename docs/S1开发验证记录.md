# S1 原型开发验证记录

日期：2026-09-14。当前为技术原型，尚未完成 S1 浏览器验收。

## 范围

本次建立 Vue / TypeScript / Cesium 工程，实现月表影像、圈层球壳、三种剖切方式、图层控制、地标、阶段演示和带来源标识的图片导出。后端、数据库、实际 DEM 与外部算法成果尚未接入。

采用 NASA LRO 2K 展示贴图；内部尺寸与演化变化是模拟数据，不能作为科研成果使用。早期阶段当前仅表达内部结构变化，没有重建早期月表。

## 已完成检查

- 几何测试：12 项，覆盖封闭边、完整/半球/四分之三保留体积、剖切范围、法向、参数边界和阶段层间连续性。
- TypeScript 类型检查和 Vite 生产构建。
- 源码格式检查：使用固定版本 Prettier。

测试命令在 `moon-web/web` 执行：`npm run format:check`、`npm test`、`npm run build`。

## 首次加载问题修复

用户报告场景无法加载后，检查已安装的 CesiumWidget 源码确认：`skyBox: false` 会跳过 Sun 和 Moon 对象创建。原初始化代码随后设置 `scene.sun.show` 和 `scene.moon.show`，访问不存在的对象，导致初始化中断。删除这两行多余操作，保留原本的天空禁用配置。格式检查、12 项几何测试与生产构建重新通过；浏览器仍无可用连接，尚未完成画面实测。
