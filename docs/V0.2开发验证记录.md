1. 完整球、半球、四分之一及反复切换；截面截图检查，并以画布像素断言防止内部全黑回归。
2. 圈层厚度、总半径联动、增删圈层、保存年代参数后刷新恢复。
3. 388 个点位加载；新增、修改、删除、GeoJSON 导入导出、刷新恢复与三维画布点击查询。
4. 阿波罗 11 号照片和可旋转登月舱模型预览。
5. 第一视角、基地自动环游、第三人称示意人物、键盘移动及退出；人工查看截图确认基地和人物实际可见。
6. 四种 NASA Trek 在线图层返回成功并显示；图层配置保存恢复；LOLA 三维高程加载。
7. 760×900 窄窗口布局、导航可达性与无横向溢出。

浏览器截图输出在被 Git 忽略的 `moon-web/web/test-results/`，运行测试可重新生成。测试中监听页面异常；本轮通过流程未出现未捕获页面异常。

## 修复与限制

剖切不再因地平线遮挡将内部对象剔除，默认观察方向朝向切面。局部基地采用明确的月面高程定位，简化几何使用 Primitive 绘制，修复近距离场景基地/人物不可见问题。

构建仍提示 Cesium 主包较大（约 4.06 MB，gzip 约 1.12 MB）；尚未完成慢网络首屏指标、目标电脑帧率、30 分钟持续演示和 Chrome/Edge 双浏览器验收。在线服务本次可用，不保证外部服务持续可用。

当前 DEM 为 0.25° 概览数据；参数模型、基地与人物为示意，人物无骨骼动画。配置保存于本浏览器，尚无共享数据库。太阳系本版未实现，已提供参考与后续实施建议。

## V0.2.1 用户反馈修正

图层管理改为可收起分类树，支持分组勾选、半选状态和叶节点设置；精简侧栏标题，减少到达控件所需的滚动。半径与厚度改为滑块加数值输入，聚焦后的滚轮可以微调。

月表漫游移除 300 米平台与边界限制，从基地外出发；地面使用月球 Globe，行走位置投影到球面，启用 DEM 时使用与地形瓦片相同的网格插值。近景月壤颗粒是程序着色示意，不能当作实测纹理或高程。

本轮 23 项单元测试、6 项浏览器测试通过，覆盖新增的分类树收起/展开、整组勾选、滑块键盘和滚轮、向基地外连续行走、DEM 下第三人称定位，并检查截图中地平线、地面、基地和人物实际可见。最后精简标题布局后，单独复测分类树和参数交互通过。构建和格式检查通过；仍未进行硬件帧率和长时间运行验收。
