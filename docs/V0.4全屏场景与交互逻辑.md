# V0.4 全屏场景与交互逻辑

2026-09-15，按已确认的“全屏 Cesium + 按需悬浮控件”方案调整。

## 页面组织

Cesium 始终占满浏览器可视区域。顶部为场景切换，右侧为当前场景可用工具，底部为悬浮时间控制。面板展开不改变画布尺寸，场景剩余区域可继续拖动和缩放。

默认进入月球探索，不展开任何编辑面板。时间轴先收为播放按钮、UTC 日期和展开入口；原有全宽页头、左侧栏、常驻统计卡和页脚布局移除。

| 场景 | 可用工具 | 时间与进入行为 |
|---|---|---|
| 月球探索 | 参数、图层、点位、光照 | 现今月表；紧凑日期控制 |
| 内部与演化 | 参数、图层、点位 | 暂停天体时间，恢复教学照明；展开参数与地质阶段条 |
| 月表漫游 | 漫游方式、光照 | 暂停时间；先选择第一视角、第三视角或基地环游 |
| 地月运动 | 运动设置 | 保留日期和播放状态，展开原生 Cesium 日期时间轴 |

月表与内部共用原有参数化模型。离开内部场景时保留其阶段、剖切方式和参数草稿；月表探索切回现今阶段。草稿仅在本次会话内保留，点击保存才写入浏览器存储。

## 面板与查询

- 点击工具展开右侧悬浮面板，再点同一工具或关闭按钮收起。
- 参数、图层、点位、光照、漫游设置只同时显示一个面板。
- 点击月面点位或列表定位后，查询结果替代工具面板。重新打开工具会关闭查询。
- 点位仍可编辑、导入导出；详情展示介绍和图片，模型按需打开，文献和链接折叠显示。
- 切换场景关闭查询与旧工具，按新场景给出适用入口。地图设置与已保存点位继续由原有 store 管理。
- 面板内部独立滚动；小窗口仍保持全屏画布，悬浮面板和时间栏缩放、换行，阶段条可横向滚动。

## 时间和漫游

日期控制仍使用 V0.3 的唯一 Cesium Clock，原生 Timeline 没有换成静态刻度。展开后可设置日期、倍速、时间跨度、前后一天；收起后保留播放状态和当前日期。地质阶段只在内部场景显示，与天体日期独立。

选择具体漫游方式后，收起设置面板。第一次进入显示操作说明，后续可手动展开。输入控件获得焦点时移动按键不再传给漫游；退出时恢复进入漫游前的相机位置、方向与视角，而不是回到统一默认视角。点击复位则明确恢复默认视角。

数据来源保留在 Cesium 署名与“数据与说明”中；教学示意或比例状态以短说明展示。软件内部统计和大块说明不再常驻覆盖场景。

## 维护与验证

- `App.vue` 管理场景和工具选择，面板仍复用独立组件。
- `immersive.css` 集中管理全屏、悬浮和响应式布局；旧侧栏、工作台头尾、常驻统计卡样式已删除。
- `AstroTimeline.vue` 管理原生时间轴与展开状态，`SurfaceNavigation.ts` 保存和恢复进入漫游前的观察视角。
- `explorer.ts` 的会话草稿与持久化保存分开，切换场景无需调用 localStorage 保存。
- 浏览器回归覆盖原有参数、圈层剖切、图层服务、点位管理、模型预览、三种漫游以及天体时间轴。
- 新增检查覆盖画布与窗口同尺寸、展开面板不挤压画布、面板互斥、阶段参数恢复、1366/760/390 px 窗口布局，以及漫游视角恢复和输入焦点隔离。

验证环境仍为 Chromium + SwiftShader；不替代目标演示电脑上的显卡性能验收。V0.3 的科学模型和数据精度范围保持不变。

本次验证：26 项单元测试通过；9 项完整浏览器回归通过，新增漫游视角/焦点检查单独通过，共覆盖 10 项浏览器用例。窄屏修正后重新通过全屏与尺寸检查。类型检查、生产构建和格式检查通过。相机恢复检查先人为旋转视角，并允许少量贴图细化造成的像素差异。
