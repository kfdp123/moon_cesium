# 科普探索展示

这一版以精选主题、地图对象和右侧展板组织科普内容。首页保留全屏 Cesium，左侧展示登月足迹、月海与火山、撞击地貌三个入口。每条科普线路可逐站浏览。虚线连接的是展览浏览顺序，不作为飞行轨迹或巡视器行驶轨迹数据。

## 点、线、面

- 任务地点、巡视器、月海和环形山采用不同图标和颜色。全球视野突出精选名称，靠近后显示更多名称，并进行屏幕碰撞避让。
- 静海、雨海、澄海、危海、风暴洋、第谷和哥白尼增加命名范围面与轮廓线。点击图标、区域或轮廓均打开同一展板。
- 数据由 `scripts/fetch-point-regions.mjs` 从 USGS / IAU Gazetteer 官方 Feature 页面取得第一套 MULTIPOLYGON，转换经度到 −180°～180°并保留五位小数。保留多面与内环层次。
- 来源：[静海](https://planetarynames.wr.usgs.gov/Feature/3691)、[雨海](https://planetarynames.wr.usgs.gov/Feature/3678)、[澄海](https://planetarynames.wr.usgs.gov/Feature/3686)、[危海](https://planetarynames.wr.usgs.gov/Feature/3671)、[风暴洋](https://planetarynames.wr.usgs.gov/Feature/4395)、[第谷](https://planetarynames.wr.usgs.gov/Feature/6163)、[哥白尼](https://planetarynames.wr.usgs.gov/Feature/1296)。

USGS 的范围表示命名地貌的大致覆盖区域，其中环形山可能采用圆形近似；它不是精确坑缘测绘、岩性分界或地质接触线。这个数据口径在开发资料中记录，界面保留地点名称与正常来源入口。

## 资料与维护

首批完整展板为阿波罗 11 号、嫦娥三号、玉兔、静海、雨海、第谷、哥白尼。图片、正文、文献与链接存放在 `public/data/lunar-points.geojson`；主题、导语和事实卡在 `src/data/pointStories.ts`。图片保存在 `public/assets/poi-media`，来源和署名见《科普资料来源》。

浏览入口采用图文列表，新增、编辑、导入、导出在二级“资料管理”中。旧浏览器目录保留用户名称和编辑内容；与旧内置版本完全一致的正文和资源条目按 `legacyPointContent.json` 比对后升级一次，并写入资料版本号，后续主动删除的图片或文献不会重新填充。内置目录下载失败时仍使用本地保存的资料。旧内置2K底图地址同步升级到8K，用户自己的底图地址保留。关闭展板不会移除已经放到地图上的模型，模型通过底部工具条聚焦或移除。

## 模块

- `PointFeatureLayer`：图标、命名区域、路线、选中状态、标签避让；与模型资源分离。
- `PointModelLayer` / `PointModelEnvironment`：单个地图模型及周围月面资源，负责贴地、相机与资源释放。
- `ExplorationWelcome`、`PointPanel`、`PointManagement`、`PointDetails`：主题入口、浏览、管理、展板。

这次属于展示与资料建设，未改变合同中算法由外部提供的安排，也未把命名范围或程序地貌作为科学计算成果。合同数据分辨率、年代参数和计算模型的验收仍按原实施计划推进。
