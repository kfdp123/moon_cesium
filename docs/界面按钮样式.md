# 界面按钮样式

2026-09-16：按用户确认的“深蓝灰＋冰蓝”效果图改造实际页面。保留全屏 Cesium、左侧工具和右侧详情布局。

## 统一约定

- 主操作使用 `primary-button`：冰蓝底、深色文字。用于分层展开、讲解播放、月球车播放、保存和新增点位。
- 普通操作使用 `secondary-button`：蓝灰底、可见边框、浅色文字。用于整体观察、上一步/下一步、返回起点等。
- 辅助操作使用 `text-button`；图标操作使用 `icon-button`。保持可见的悬停和键盘焦点反馈，不能只靠文字颜色提示可点击。
- 互斥选择使用 `segmented-control` 与 `aria-pressed`。剖切和月球车视角共用该样式；选中项有底色、边框和底部标记。
- 圈层按钮保留与模型一致的材质色点，选中时加勾选图标。窄屏排为两列。
- 一般操作按钮至少 44px 高，主字号 16px，支持已有大字模式。危险操作使用局部红色提示，不扩大为全局强调色。
- 控件颜色与圆角集中在 `src/style.css` 的 CSS 变量中；`workspace.css` 管理面板内容，`immersive.css` 管理悬浮布局和场景控件。避免各模块独立追加一套按钮规则。

## 交互调整

内部展台的剖切下拉框改为“完整球 / 半球 / 四分之一”直接选择，继续调用原有剖切和整体观察逻辑。

讲解面板保留拖动；拖动和窗口缩小后的边界限制在时间轴上方，避免底部按钮被遮挡。窄屏讲解主按钮独占一行，前后步骤排在下一行。

星空与月球材质使用已有资源，本次没有使用效果图替换三维场景，也没有增加渲染依赖。

## 验证入口

- `e2e/interior.spec.ts`：圈层展开、聚焦、三个剖切按钮、返回探索。
- `e2e/evolution.spec.ts`：讲解暂停/继续、步骤切换、面板拖动及窄屏时间轴遮挡回归。
- `e2e/immersive.spec.ts`：全屏画布、悬浮面板、响应式、步行漫游。
- `e2e/rover.spec.ts`：行驶暂停、三个相机模式、键盘观察与退出。
