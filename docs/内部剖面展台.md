# 内部剖面展台：第一轮展示升级

2026-09-15。改造前版本已提交到 GitHub：`541a9ce`。本轮改造先保留在本地供体验。

## 使用

进入“内部与演化”，默认显示四分之一剖面，参数面板按需从左侧打开。

- “分层展开 / 合拢圈层”：平滑移动各层；间距按当前圈层半径计算，镜头自动调整构图。展开时显示圈层名称。
- 点击圈层实体、展开图中的名称，或左上角的圈层按钮：聚焦该层，暂时隐藏遮挡它的外部圈层，弱化内部其他层，右侧显示资料。
- “整体观察”或关闭详情：恢复所有未被手动隐藏的圈层与整体视角。
- 下拉菜单支持四分之一剖面、半球剖面和完整球体。年代、半径、厚度及颜色仍使用原来的参数系统。
- 退出模块后恢复月表场景和原有点位显示；内部展示期间暂不显示月表点位，避免与圈层混淆。

## 实现

- `components/InteriorControls.vue`：展台交互，与原参数编辑界面分开。
- `scene/interiorAppearance.ts`：模型空间的程序纹理与展示光照，纹理随圈层移动。材质采用常规 Primitive / PerInstanceColorAppearance，不依赖 UE5 或外部贴图库。
- `scene/InteriorExhibit.ts`：展开间距、相机聚焦、圈层名称与动画生命周期。展开只更新已有网格的位置，不逐帧重建球壳；静止后停止重复更新。
- `scene/MoonScene.ts`：集成原有几何、剖切、点选与地图功能。

纹理为视觉表达，不是内部实测影像。展开间距不是月球真实空隙；该模式保留“展开视图”短标记。第一轮完成剖面质感、分层展开和圈层聚焦；连续剖切角度尚未加入。

浏览器回归覆盖完整球与剖面反复切换、展开合拢、聚焦与退出、年代和半径调整；原有球壳几何测试继续检查闭合及 Cesium 渲染数据管线。

## 第二轮：演化过程与分步讲解

底部播放按钮现在启动约 60 秒、8 步的字幕讲解：完整月球 → 打开剖面 → 分层观察 → 聚焦月幔 → 岩浆海 → 分异与结晶 → 撞击与冷却 → 现今月球。支持暂停、继续、前后切换、结束和完成后重新播放。讲解没有合成语音。

单独点击年代也可以观察过程；左上角“暂停过程 / 播放过程”控制视觉动画。拖动模型、选择圈层或打开参数面板时暂停讲解，便于自由观察。手动切换年代退出讲解，离开模块释放动画与播放循环。

- 岩浆海：浅部熔融区域使用流动亮纹，带亮点的循环颗粒表达物质流动。
- 分异与结晶：浅色颗粒上浮、金色颗粒下沉；亮度随演示时间逐渐减弱。
- 撞击与冷却：一次局部撞击的运动轨迹和扩散环，随后淡出；浅部余热表现逐渐减弱。撞击是重复示意，不表示真实撞击频率。
- 早期表面使用程序材质；现今阶段恢复已有月表影像。不会将现代月表直接贴到早期阶段。

展开或聚焦单层时隐藏过程颗粒，避免粒子留在原位置；该层材质仍可展示热状态。粒子路径、冷却速度、颜色和字幕时间均为科普演示，不是温度、流速、年代的物理解算；圈层尺寸继续读取已有可编辑阶段参数，讲解不会覆盖保存的尺寸。科学内容参考 [NASA 月球形成](https://science.nasa.gov/moon/formation/)，具体阶段年代和物态仍需项目科学资料核定。

新增代码：`data/evolutionTour.ts` 管理讲解步骤和短字幕；`stores/evolutionTour.ts` 管理播放状态；`components/EvolutionTour.vue` 管理字幕控件及计时生命周期；`scene/LunarEvolution.ts` 更新材质时间与粒子，`scene/evolutionParticles.ts` 定义示意路径。动画通过材质 uniform 更新，不逐帧改 Vue 场景状态或重建几何。渲染卡顿和后台标签页会放慢演示，而非跳过步骤。
