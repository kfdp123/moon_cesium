# 月球智能体问答接入

更新日期：2026 年 9 月 19 日。

## 使用方式

左侧工具栏新增“月球智能体”，在月球探索、内部与演化、月表漫游、地月运动以及模型展台均可打开。输入问题后逐段显示回答，支持连续追问、停止生成、失败重试和清空对话。Enter 发送，Shift + Enter 换行。切换面板保留当前对话，刷新页面后重新开始。

先选择点位、圈层或科研图层，或在科研数据模式下查询月面位置，再打开智能体，可直接询问“这个位置的查询结果说明什么”。打开问答时保留选中对象，详细信息面板暂时收起。

智能体解释月球科学和当前场景，不直接执行地图控制或科研算法。

## 数据与回答依据

每次提问提交最近不超过 12 条对话，以及当前场景、年代、可调圈层参数、选中点位、选中圈层、已显示科研图层和当前网格查询结果。后端按问题关键词和已选对象，从以下本地文本中选取最多 5 条资料：

- `public/data/lunar-points.geojson`：点位名称、介绍及来源。
- `public/data/cesium_data/catalog.json`：科研图层名称、单位、来源、说明、显示范围和统计信息。
- `server/knowledge.mjs`：系统操作说明。

开发时读取 `public/data/`，正式运行读取构建后的 `dist/data/`。未安装科研数据时仍可回答一般月球知识和系统操作问题。回答下的“参考资料”列出本次提供的条目，并与正文引用编号对应；有来源网址时可点击访问。

仅发送问题、上述场景文字和少量资料摘录到 DeepSeek，不上传 PDF 全文、GLB、影像或原始科学网格。网格仅提交当前查询所得的数值。展示参数、反演模型、观测资料和一般科学知识在提示词中分别约束；没有位置查询结果时不推测该位置的实测数值。

资料选择采用可维护的本地关键词检索，无外部向量库。当前不自动搜索互联网，也不解析论文全文。

## 配置

本机的真实密钥已存入 `moon-web/web/.env.local`，接入信息另外记录在项目根目录 `.local/DeepSeek接入信息.md`。两处均被 `.gitignore` 排除，不能放入 `public/`、`dist/` 或前端 `VITE_` 环境变量。

新环境可复制 `moon-web/web/.env.example` 为 `.env.local`，然后填写：

```dotenv
DEEPSEEK_API_KEY=填写服务端密钥
DEEPSEEK_MODEL=deepseek-flash
HOST=127.0.0.1
PORT=4173
```

运行服务也可直接注入同名环境变量，已有进程环境变量优先于配置文件。修改密钥或模型后重启服务。`HOST`、`PORT` 用于正式 Node 服务；开发服务固定为 `127.0.0.1:5173`。

接口使用 DeepSeek 官方 Chat Completions，固定地址为 `https://api.deepseek.com/chat/completions`。当前默认模型为 `deepseek-flash`，启用流式输出、关闭思考过程输出，单次回答最多 2400 个 token。

官方说明：[API 入口与模型](https://api-docs.deepseek.com/)、[Chat Completions 参数](https://api-docs.deepseek.com/api/create-chat-completion/)。模型后续变更时只需调整服务端配置，并核对官方文档。

## 启动与部署

需要 Node.js 20.19 或以上兼容版本。

开发运行：

```powershell
cd moon-web/web
npm ci
npm run dev
```

访问 `http://127.0.0.1:5173/`。Vite 插件同时提供同源 `/api/lunar-chat`，前端不接触密钥，不需要另开问答后端。

正式运行：

```powershell
cd moon-web/web
npm run build
npm start
```

访问 `http://127.0.0.1:4173/`。正式 Node 服务同时提供 `dist/` 静态资源和问答接口。仅将 `dist/` 放在普通静态服务器上不能使用问答功能。

向其他机器部署时保留 `dist/`、`server/`、`package.json`，在目标机器单独配置 `.env.local` 或环境变量。正式服务只使用 Node 内置模块，不需要安装前端构建依赖；构建应在已有依赖的开发或构建环境完成。科研数据随本地构建复制至 `dist/data/`，通过独立数据交付部署，不加入 GitHub 仓库。

如果使用已有 HTTPS 反向代理，需要将页面和 `/api/lunar-chat` 指向同一 Node 服务，保留原始 `Host`，关闭问答接口的响应缓冲，并将读取超时设为至少 100 秒。公网访问的账号认证和额度限制由部署侧网关统一配置。保持 `.env.local` 与 `.local/` 在网站静态目录之外。

## 接口与代码位置

浏览器向 `POST /api/lunar-chat` 发送 JSON：

```json
{
  "messages": [{ "role": "user", "content": "月海如何形成？" }],
  "context": { "scene": { "name": "月球探索" } }
}
```

后端返回逐行 JSON（NDJSON）：先返回 `sources`，再返回多条 `delta`，最后返回 `done`。连接过程中出错返回 `error` 事件；建立流之前的错误使用非 200 状态和 `{"error":"提示文字"}`。客户端只在收到 `done` 后认定回答完整。

| 文件 | 职责 |
| --- | --- |
| `src/components/LunarAssistantPanel.vue` | 对话面板、输入及参考资料 |
| `src/stores/lunarAssistant.ts` | 对话状态、历史、停止和重试 |
| `src/services/lunarChat.ts` | 请求与 NDJSON 流解析 |
| `src/App.vue` | 工具栏入口及当前场景上下文 |
| `server/chat.mjs` | 同源检查、输入限制、DeepSeek 代理与错误转换 |
| `server/deepseek.mjs` | DeepSeek SSE 流解析 |
| `server/knowledge.mjs` | 本地资料检索与提示词 |
| `server/config.mjs` | 读取服务端环境配置 |
| `server/index.mjs` | 正式环境静态服务与问答接口 |
| `vite.config.ts` | 开发及预览环境的问答接口 |

服务器不保存对话和问题日志。单进程最多同时生成 2 个回答，每分钟最多接受 12 个有效提问，单次请求 90 秒超时；停止或关闭连接会取消上游请求。单条消息最多 6000 字符，请求体上限 96 KB，场景上下文上限 20000 字符。

## 验证与常见问题

```powershell
npm test
npm run test:server
npm run build
npm run test:e2e -- e2e/lunar-assistant.spec.ts
```

浏览器测试使用固定响应，不产生 DeepSeek 费用；运行前先启动开发服务。后端测试覆盖分块 UTF-8、流中断、输入校验、资料选择、授权错误脱敏和超时取消。

- 提示未配置密钥：检查 `.env.local` 所在位置和变量名，重启服务。
- 提示授权失败：核对服务端密钥是否有效。
- 提示余额不足：检查 DeepSeek 账户余额。
- 提示模型不可用：核对 `DEEPSEEK_MODEL` 与官方模型列表。
- 提示超时或连接失败：检查服务器到 DeepSeek 的网络连接；点击重试。
- 只显示一般知识、没有当前位置的数值：先完成科研数据位置查询，再发送问题。
- 页面正常而问答返回 404：检查是否仅部署了静态文件，以及代理是否转发 `/api/lunar-chat`。
