# V0.3 时间轴与天体运动

实现日期：2026-09-15。服务于在线 Web 科普演示，保留 Cesium 原生时间轴，新增日期驱动的月球运动和太阳照明。

## 使用方式

1. 顶部进入“天体运动”，底部使用“日期时间 · 天体运动”。时间显示为 UTC，北京时间需加 8 小时。
2. 可拖动 Cesium 时间轴，输入日期，前进/后退一天；播放支持实时、1 秒对应 1 分钟/1 小时/1 天/7 天。时间轴跨度可选 1 天、7 天、30 天、1 年，“定位当前”重新居中。
3. “月球近景”显示按日期计算的太阳照射方向。勾选“观察自转”后，时间推进时相机保持惯性方向，月表在视野中转动；取消后镜头跟随月面。
4. “地月全景”从地心惯性视角展示月球公转和同步自转。默认地月距离缩为 1/8、月球半径放大 3 倍，便于大屏看清；可切换真实比例。太阳箭头表示从地球朝向太阳，地球为蓝色示意球。
5. “前往基地看阴影”会暂停时间，选择附近适合观察阴影的白昼时刻，并进入月面第一视角。基地模型向月面投影，可开关对比，推进时间可观察光照变化。漫游时镜头始终固定在月面，WASD 等原有操作保留。
6. “地质年代 · 内部演化”保留原有早期阶段与参数模型。选择年代会暂停日期播放并恢复教学照明；地质年龄不会被换算为远古天文日期。重新进入“天体运动”或播放日期即可恢复太阳照明。

日期范围为 2000-01-01 至 2100-01-01；初始暂停在当前日期。日期、播放状态、光照开关暂不保存到本地存储。

## 代码与坐标

| 文件 | 职责 |
|---|---|
| `stores/astronomy.ts` | 唯一 Cesium Clock、播放/定位、视图和显示选项 |
| `components/AstroTimeline.vue` | 原生 Timeline、可读控制栏和事件清理 |
| `scene/lunarEphemeris.ts` | Simon 1994 太阳/月球地心惯性位置，IAU 2000 月固姿态 |
| `scene/LunarLighting.ts` | 惯性太阳方向变换到月固坐标，局部投影，相机随日期变换 |
| `scene/OrbitalScene.ts` | 地月球体、日期采样轨迹、太阳方向与比例切换 |
| `scene/sunAppearance.ts` | 基于 DirectionalLight 的漫反射模型材质 |
| `components/AstronomyPanel.vue` | 场景选项、物理量展示、基地观察入口 |

月球近景保持原有月固坐标，点位、DEM、圈层和月面导航不随日期改写。全景使用地心惯性坐标。任一时刻只挂载一个 Viewer，两个视图共用同一时钟，防止重复推进时间；切换视图保留日期。Viewer、ClockViewModel、时间轴及监听器在卸载时释放。

月球姿态使用锁定 Cesium 版本自带 Moon 所采用的 `IauOrientationAxes`，补充最小 TypeScript 声明。测试约束地球始终位于月球近侧、太阳纬度接近月球赤道、日转角约 13°；这些是合理性与坐标检查，不是外部高精度星历校准。

Cesium 普通模型材质默认漫反射含相机方向照明，本次新增的小型着色片段明确采用太阳光方向。月球 Globe 使用 Cesium 自身的太阳照明与阴影接收。基地模型只投影、月面只接收，避免示意几何上的自阴影条纹；未实现模型之间的阴影接收。

## 科学范围与显示限制

- 太阳和月球位置为 Cesium 内置解析近似，月球姿态采用 IAU 2000。未接入 JPL DE440/SPICE，也未验证用于精密预报所需的误差范围。
- 自转与公转按同一日期计算，包含姿态公式中的天平动项；不是把月球按地球的 24 小时周期旋转。
- 地心视角受光比例是几何相位估算，忽略日月食、地球反照、实际地球观测点和大气。
- 全景轨迹为当前日期附近 28 天位置的采样线，每 7 天刷新。演示比例会改变几何尺寸关系；真实比例下月球在全景中较小，可放大查看。
- 局部阴影仅为基地模型向月面投影；没有真实地形自身遮挡、环形山阴影精细分析、半影或日月食。阴影距离限于相机附近 500 米。现有全球 0.25° DEM 不足以进行基地选址和精细日照分析。
- 月面保留少量环境亮度便于教学观察，没有模拟真实月壤 BRDF。地球无真实影像、云层；太阳只用方向箭头表示，没有扩展为完整太阳系。
- 内部参数、基地和人物继续明确标注教学示意。天文日期与合同要求的地质年代场景独立，不能据此声称已完成远古轨道或内部演化算法。

## 验证范围

新增单元测试覆盖月球姿态、距离范围、太阳方向、旋转速率和矩阵独立性。新增浏览器测试覆盖日期拖动、倍速与暂停、两视图时间连续性、真实比例切换、地质年代隔离，以及固定相机下开关投影的月面像素差异。原有圈层剖切、参数编辑、图层、点位、模型与漫游回归仍须通过。

浏览器验证使用 Chromium + SwiftShader；这验证渲染正确性，不代表演示电脑的独立显卡帧率。构建保留 Cesium 主包体积提示，后续可按首屏加载需求再拆包。

本次结果：26 项单元测试、8 项 Playwright 浏览器测试通过，TypeScript 与生产构建通过，Prettier 检查通过。人工检查了月球昼夜、地月全景、基地投影与 760 px 窄窗口截图。导出的场景图片附带 UTC 日期、比例和当前视图对应的来源说明。

## 2026-09-16 中文刻度补充

日期时间轴刻度改为中文年月日；跨度小于两天时显示时分秒，放大至一小时内时保留毫秒精度。输入区标注“世界时”，继续使用 UTC，不自动转换北京时间。播放、拖动、缩放和跨场景共用时钟的行为保持一致。

实现仅替换当前 Timeline 实例的 `makeLabel`，并读取其跨度决定标签精度；该钩子属于已锁定 Cesium 1.132 的未公开接口，未修改依赖源码或全局原型。升级 Cesium 时须回归中文刻度、缩放测量与拖动行为。
