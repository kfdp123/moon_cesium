# 后续扩展：深空探索

记录日期：2026-09-16。

状态：已记录为后续扩展完善项，尚未排期、尚未启动开发。用户本次仅要求保存讨论结论，不修改功能代码。本项不代表新增合同验收要求。

## 参考与可行性结论

参考视频：[扩展 Cesium 实现深空可视化模式](https://www.bilibili.com/video/BV1HD3kzBEvo/)。已查看视频简介与代表画面；画面包含星空、太阳光晕、地月天体、航天器、红色运动轨迹，以及远近视角和跟随目标切换。

在现有 Vue / TypeScript / Cesium 项目上扩展可行，当前没有为此引入 UE5 的必要。主要观感来自大尺度空间、目标间镜头切换、随时间变化的天体和航天器运动，不只是替换背景贴图。

视频简介声称八大行星运动计算误差约 1 公里；其适用时间范围、参考系和验证方法尚未核实，不作为本项目精度承诺。没有确认参考项目是否开源，也没有取得其代码或素材复用许可。

## 建议分阶段范围

### 第一阶段：地月深空演示

以现有“地月运动”为基础，增加深空探索入口。具体命名和页面归属在启动时确定，延续全屏 Cesium、按需悬浮控件的布局。

- 改善星空素材、太阳可见球体与光晕、地月明暗效果；避免重复绘制天体。
- 增加一艘示意探测器，播放带时间的轨迹，区分已飞行与未来路径。
- 提供自由观察、天体聚焦、航天器跟随和返回全景。
- 复用现有唯一日期时钟及 Cesium 时间轴，统一暂停、拖动、倍速与目标位置。
- 保留真实比例与展示比例；展示时放大的天体尺寸明确标识。

目标：先实现参考视频的主要空间观感与交互流程，再决定后续扩展范围。

### 第二阶段：太阳系全景

- 接入太阳与八大行星的位置、半径、自转姿态、纹理和来源说明。
- 提供天体选择、轨道显隐、天体近景、时间播放与科普查询。
- 处理远距离下的天体可见性、标签密度和资源按需加载。
- 根据用户对第一阶段的评价，确定画面风格与展示比例规则。

### 第三阶段：跨尺度与精度完善

- 完善“太阳系全景 → 天体近景 → 地月空间 → 月表”的平滑过渡。
- 若确有需要，再研究从月面连续缩放到太阳系的无缝浏览，验证坐标精度、深度缓冲、相机控制及近远景资源切换。
- 按实际精度要求接入并验证星历或外部算法成果，记录支持时间范围、采样间隔、插值方法与误差。
- 结合整体离线计划，打包许可允许分发的贴图、模型和指定时间段星历。

## 数据与维护约定

沿用“算法由外部提供、系统负责接入展示”的分工；不把示意路径作为真实探测任务轨迹。外部成果至少明确时间及时间标准、位置参考系、单位、姿态约定、有效时间范围和数据来源。必要时可评估 JPL Horizons 星历，预取指定时间段后本地插值，避免逐帧请求外部服务。

轨道数据、天体配置、场景绘制和相机交互分别承担清晰职责，复用现有时钟与资产管理，保持代码可读，不为尚未确认的需求预建复杂框架。

星空作为视觉背景与严格的天文观测天空是不同要求；若未来需要准确星空方位，须统一参考系与时间变换后单独验证。太阳方向、天体位置与明暗表现应来自一致的计算约定。

## 启动前确认与验收方向

启动时确认目标电脑配置、首批天体与探测器范围、演示时间跨度，以及轨迹采用示意数据还是实际任务数据。目前不承诺开发工期、帧率或公里级精度。

建议验收检查：时间轴拖动后天体、航天器和轨迹保持同步；聚焦、跟随、自由观察切换稳定；近远景无明显抖动或穿模；真实/展示比例可区分；素材有来源与许可记录；在目标电脑记录加载时间和帧率。高精度数据要求另行与权威参考值比较。
