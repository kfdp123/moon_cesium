# 月球 Web 系统开发任务清单

日期：2026-09-14。依据：[详细实施方案](月球Web科普系统详细实施方案.md)；调研：[开源调研与复用评估](开源调研与复用评估.md)。

当前已完成 V0.2 参数化与科普演示扩展，23 项单元测试、4 项 Playwright 浏览器测试和生产构建通过，具体范围见 [V0.2 验证记录](V0.2开发验证记录.md)。尚未完成目标电脑性能、长期运行及全部合同验收。以下保留原合同任务编号；本轮新增的点位、图层和漫游以 [V0.2 扩展说明](V0.2扩展实施与数据说明.md) 为准。第一版在线，离线在 S7。

## 1. 执行顺序

S0 → S1 技术验证 → S2 工程与数据接口 → S3 探索/模拟成果 → S4 演化演示 → S5 真实数据整合 → S6 在线交付。

S7 为后续增强。S1 如不能通过，先定位并记录原因，再对相同场景验证替代技术。常规修复直接进行；更换引擎或改变范围时提供比较结果让用户决定。

## 11. 代码评审约定

用户要求：系统代码可维护、易读，避免过多防御性代码。每阶段按以下原则检查，无需为此另建复杂流程：

- 模块和命名能直接表达业务；没有无实际用途的抽象层、空适配器或通用框架。
- 外部输入在边界完成必要校验，内部不重复判空、重复转换或层层兜底。
- 错误在合适的位置处理，不吞错，不用默认数据掩盖错误。
- 注释解释原因与科学约定；测试覆盖重要行为，不机械复述实现。

具体规则见实施方案第 11.1 节。这项要求适用于后续所有开发阶段。
