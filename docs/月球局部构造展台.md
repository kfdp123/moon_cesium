# 月球局部构造展台

入口：**内部与演化 → 局部构造**。返回“整体月球”恢复原来的圈层场景；切换顶栏模块会退出局部展台。

## 本次实现

参照原 GLB 的“地表＋地下剖面”组织形式，重新生成三套月球主题模型。没有复用原文件的植被、河流、房屋、网格或贴图。原始 GLB 保留不动，新模型通过 Cesium 程序网格绘制，不需要额外加载约 50 MB 的素材，也没有增加渲染引擎或运行时依赖。

| 模型 | 可查询部件 | 过程步骤 |
| --- | --- | --- |
| 岩浆海 | 连续熔体、散热表面 | 熔融 → 对流 → 向表面散热；保持无结晶设定 |
| 分异与火山 | 深部岩石、月壳、岩浆储集区与通道、火山与玄武岩 | 分层背景 → 岩浆上涌 → 熔岩铺展 |
| 撞击与冷却 | 下伏岩石、破碎岩层、月表与坑体、撞击熔融物 | 撞击前 → 开挖与熔融 → 冷却后的剖面 |

支持拖动旋转、滚轮缩放、透视／俯视／剖面预设、部件隐藏与恢复、点击模型查询、部件高亮、右侧说明与参考链接、步骤滑块、过程播放／暂停、带示意说明的图片导出。每段过程约 4 秒，完整播放约 12 秒，是讲解节奏，不是地质时间比例。操作模型或后台隐藏页面时暂停播放。没有播放时按需渲染。

## 合同对应与边界

依据原合同 `向下解析延拓.pdf` 文件第 3–4 页（印刷页码第 2–3 页）“技术服务内容”：

- **第 2 条**：补充剖面浏览、构造信息查询、内部与表层联系、过程对比展示。局部构造是全局圈层视图的补充，不属于实测数据重建。
- **第 3 条第 (1) 项**：岩浆海模型展示无结晶熔体与散热过程；月核继续在整体月球中展示。
- **第 3 条第 (2) 项**：分异与火山模型补充月壳、火山和岩浆通道的直观表达。没有恢复风暴洋真实地理分布，也没有将风暴洋解释为已确定的撞击成因。
- **第 3 条第 (3) 项**：撞击与冷却模型补充撞击坑体、岩石破碎、熔融与冷却。双层月核及全球圈层仍属整体月球功能；潮汐锁定等动力学机制不由此块体表现。

这次完成的是上述条款的**部分展示能力**，不能据此判定合同整体验收通过。重力向下解析延拓算法、真实科学参数、统一数据库、全球 DEM 的最终精度及实体制作均不在本次新增内容中。

三个局部模型使用自己的过程步骤，不挪用 Cesium 的现代日期作为地质年代。入口默认关联当前整体阶段（现今状态默认进入撞击模型），局部切换不修改整体月球参数。分异与后续火山活动被组织在同一概念剖面中，不声称是同时发生的事件。

### 科学表达限制

- 块体没有经纬度和实测深度；尺寸、厚度、火山坡度、坑体几何、颜色、流线、速度和冷却节奏均为示意。
- 底面是裁切边界，不是月核或某个真实圈层边界；局部岩浆储集区不可误读为月核。
- 岩浆海表面的暗纹不表示已形成月壳；无结晶场景不加入漂浮晶体。
- 撞击剖面中规则形状的破碎层和熔融透镜体是简化表达；仅较大的复杂撞击坑可能具有中央隆起。
- 不声称在约 38 亿年前月球已完全停止火山活动；不把该模型称为南极—艾特肯盆地复原。
