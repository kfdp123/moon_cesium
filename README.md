# 月见 · Moon Explorer

面向科普演示的月球 Web 系统，使用 Vue、TypeScript 和 CesiumJS。当前为 V0.6 月球车轨迹漫游与科研数据接入版。

## 已实现

- 月球智能体问答：接入 DeepSeek，支持流式回答、连续追问、停止和重试；结合当前点位、圈层及科研查询结果提供参考资料。密钥仅由服务端读取。
- 科普探索首页提供三条主题线路；任务图标、月海和环形山的命名范围线面可点击查询，首批七个精选展板补齐图片、事实、介绍与文献。
- 点位模型缩略图直接将 GLB 放到主地图，设备配有月壤与碎石环境，环形山与月海采用带纹理的地貌网格。
- 月球车沿月面闭合示意轨迹行驶，支持自由观察、固定跟随、车载第一视角，以及暂停、调速和回到起点。使用提供的本地 GLB 模型。

- Cesium 铺满浏览器：四个观察场景、按需悬浮工具、互斥面板；16 px 主字号、大字模式和独立面板滚动。
- 月表与内部统一参数化：半径、厚度支持滑块、数值输入和聚焦滚轮微调；颜色、圈层增删、显隐、完整球/半球/四分之一剖切。
- 3 个早期阶段和现今状态；每个年代可保存参数、恢复默认，支持阶段播放。
- 分类树管理 NASA LRO 影像、四种 NASA Trek 在线影像/地形专题/地质图、实际 LOLA 0.25° 三维高程，支持分组勾选和按需展开设置。
- 15 个重点科普点位，三维点击查询、增删改、GeoJSON 导入导出和本地保存；普通批量地貌点保留在迁移归档中，不随首屏目录加载。
- 点位文字、图片、可旋转 GLB 模型、文献和相关链接；缺项不填造。
- 第一视角月表步行、基地自动环游、第三人称示意人物；WASD 移动、方向键转头、Shift 加速，可走离基地，随球面与已启用 DEM 高程定位。近景月壤纹理为程序生成的教学示意。
- 场景图片导出，保留数据来源或模拟说明。
- 保留 Cesium 原生日期时间轴，支持拖动、UTC 日期、暂停/播放和倍速；与地质年代分别控制。
- 月球近景自转、太阳昼夜照明、基地向月面投影；地月全景显示绕地公转、同步自转、太阳方向，可切换演示比例与真实比例。
- 地月场景使用 WGS84 地球参考椭球和本地 NASA Blue Marble 全球影像，支持大气光晕、按日期自转、聚焦地球与返回全景。影像为 2004 年 9 月合成图，不代表当前天气。

内部半径、阶段变化、基地与人物是教学示意。现今月表影像与高程不能当作早期表面重建。科研成果以 `cesium_data` 静态数据目录按需加载，包含重力异常、月壳厚度、密度和微波亮温网格；场景数据仍采用浏览器本地保存，不包含服务端数据库管理，智能体通过 Node 服务调用 DeepSeek。点位自动保存；年代参数与地图配置需点击保存，均存于本浏览器。

## 本地运行

需要 Node.js 20.19 及以上兼容版本；本次使用 Node 20.19.1 验证。

```powershell
cd moon-web/web
npm ci
npm run dev
```

浏览器打开终端显示的 `http://127.0.0.1:5173/`。页面占用该端口时会报错，不自动切换到其他端口。

```powershell
npm test
npm run test:server
npm run build
npm start
npm run test:e2e
```

`build` 包含 TypeScript 类型检查。正式运行使用 `npm start`，默认地址 `http://127.0.0.1:4173/`，同时提供页面和智能体接口。`dist/` 必须通过 HTTP 服务访问，不能直接双击 HTML；单独使用普通静态服务器时无法进行智能体问答。第一版支持在线使用，字体来自 Google Fonts；未完成断网验收。

智能体的密钥放在 `moon-web/web/.env.local` 的 `DEEPSEEK_API_KEY` 中；新环境参考 `.env.example`。本机已配置，密钥及私有接入记录不进入 Git。完整说明见[月球智能体问答接入](docs/月球智能体问答接入.md)。

月表资源可通过 `.env.local` 中的 `VITE_MOON_TEXTURE_URL` 指定。默认使用仓库附带的 NASA 8K 展示影像。不要把凭据写进前端环境变量。

## 代码结构

```text
moon-web/web/src/
  data/moon.ts              # 阶段、圈层、地标与来源配置
  scene/shellGeometry.ts    # 独立于渲染引擎的球壳网格生成
  scene/MoonScene.ts        # Cesium 生命周期、相机、显示与拾取
  scene/lunarEphemeris.ts   # 现代日期太阳/月球位置和月球姿态
  scene/LunarLighting.ts   # 月固坐标光照与相机自转观察
  scene/OrbitalScene.ts    # 地心惯性坐标下的地月全景
  stores/explorer.ts        # 页面和场景的共享状态
  stores/astronomy.ts       # 两个视图共用的唯一日期时钟
  components/              # 场景容器、圈层列表
  App.vue                  # 页面布局和演示控制
```

几何测试检查封闭边、体积比例、法向和阶段边界；另有模型编辑、点位输入和 DEM 插值测试。浏览器测试使用独立 Chromium，首次运行先执行 `npx playwright install chromium`，并保持开发服务器运行；在线图层测试需要联网。避免重复边界校验和预先抽象，具体约定见实施方案第 11.1 节。
